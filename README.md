# Ccan Growth - Landing Page

## Estrutura do Projeto

Este projeto contém dois diretórios principais:

### 📁 deployment/
Contém os arquivos prontos para deployment em produção:
- `index.html` - Arquivo principal
- `css/` - Arquivos CSS minificados
- `js/` - Arquivos JavaScript minificados  
- `images/` - Imagens otimizadas
- `favicon.ico` - Ícone do site

### 📁 source-code/
Contém o código fonte completo do projeto React:
- `src/` - Código fonte React
- `public/` - Arquivos públicos
- `package.json` - Dependências do projeto
- Todos os arquivos de configuração

## 🚀 Como usar para deployment

1. Extraia o conteúdo da pasta `deployment/`
2. Faça upload de todos os arquivos para a pasta `public` do seu domínio
3. Mantenha a estrutura de pastas exatamente como está
4. O site estará online imediatamente!

## 🛠️ Como editar o código

1. Navegue até a pasta `source-code/`
2. Execute `npm install` para instalar as dependências
3. Execute `npm run dev` para iniciar o servidor de desenvolvimento
4. Edite os arquivos em `src/`
5. Execute `npm run build` para gerar uma nova versão de produção
